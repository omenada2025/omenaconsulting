Your process — from V0 to Support PM Accept

You own the factory version through the 6-week cycle. Weekly status continues. Ownership moves only after Support PM accepts handover.

1. Sign in 2. Set ownership 3. Runway 4. Gates 5. Handover 6. Home

1. Sign in

1

Open the dashboard and sign in with your username + access code.

2. Create / update your weekly report as Live PM

2

Go to Update Reports (or Add Status). On every update set:

  • Functional responsibility = Live PM (Builder)
  • Ownership stage = In delivery (pre-handover) — or Handover in progress near Week 6
  • Version / cycle label = e.g. Checkout Hub · v1.2 (keeps tracking when live + next version run in parallel)
  • V0 received date = date you received the formal V0 / pack (starts the 6-week clock)
  • Factory week = leave Auto, or set 1–6 manually if needed
Rule: Empty V0 date = this update is not on the factory runway (weekly status only).

3. Use the Factory cycle runway

3

Open your report. Below the ownership fields you see the Factory cycle panel: W1–W6, current week highlighted, gate weeks marked.

Weeks 1–4Discover → MSP → TO-BE → Implement. Capture evidence at gates 1 and 3.
Weeks 5–6Validate with Support PM rehearsal; build kits; prepare Accept.

4. Gate evidence (weeks 1, 3, 5, 6)

4

On gate weeks, complete the evidence listed on the Factory panel and keep governance artifacts current.

  • W1: observed features / baseline
  • W3: backlog + TO-BE / acceptance criteria
  • W5: QA evidence · Support PM reverse demo rehearsal · limitations
  • W6: Launch / Run / Live Product kits ready for Accept
Do not mix live-ops bug tracking into this factory version’s weekly update. Use a separate live version stream if Support PM already owns the previous release.

5. Prepare handover (you do not Accept)

5

Set ownership stage to Handover in progress. Complete the three kits in Product Governance evidence. Only Support PM clicks Accept.

After Accept: you move to the next product or next version cycle. Support PM owns Live ops.

6. Check Home each week

6

Home shows Week Close gaps and Factory gate items due for your products.
